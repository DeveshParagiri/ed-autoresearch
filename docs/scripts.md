# Scripts

| Script | Role |
|---|---|
| `reproduce_paper.py` | Rebuild BA for Models C/D/E (+ optional fFire) |
| `reproduce_modelC.py` | Single param JSON → `burntArea.nc` |
| `assemble_continental.py` | Model E per-continent stitch |
| `assemble_combustion_continental.py` | Per-continent combustion → fFire |
| `verify_paper_ilamb.sh` | Official `ilamb-run` vs GFED5 |
| `run_ilamb.sh` | Thin ILAMB wrapper |
| `optimize_modelC_coupled.py` | Parameter re-fit (lab) |
| `validate_holdout.py` | Held-out years |
| `validate_holdout_cells.py` | Held-out spatial tiles |
| `tune_combustion_params.py` | Global combustion beta fit |
| `tune_combustion_continental.py` | Per-continent combustion beta fit |
| `compute_emissions.py` | Shared fFire helpers |
| `scores.py` | Shared ILAMB-style component scores |
| `score_spatial.py` | Per-cell r / σ / slope (used by optimizer) |
| `download_inputs.sh` | Optional pinned input bundle |
| `prep_monthly_inputs.py` | Raw climate → monthly npy |

Paper figures under `paper/figures/` are the manuscript panels (Typst). They are **not** regenerated by scripts.
