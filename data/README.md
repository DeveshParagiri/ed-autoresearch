# Data layer

The data layer gives every scientific asset one canonical path inside this project. Large files are ignored by Git, but they are not owned by an external data root. Older workspaces may symlink to these paths. `catalog.toml` states each item’s role, requirement profile, path, and integrity checks. `sources.toml` records source identity, acquisition, release, coverage, units, preprocessing, limitations, access terms, integrity, experiment use, and recovery instructions; for non-repository assets, its `source_path` must equal the catalog path.

`inputs/` contains climate drivers, ecosystem state, coupled state, human drivers, and candidate mechanism inputs. `benchmarks/` contains GFED observations, original GFED products, tracked ILAMB configurations, the native ED baseline, TRENDY outputs, and selected ILAMB-ready comparison models. `reference/` contains pinned conversion code and source notes. `derived/` is reserved for reusable products generated by recorded runs.

Run `uv run python scripts/check_workspace.py` for a read-only integrity report. Run `bash scripts/install_all_data.sh` for the same final check through the procurement entry point. Pass `--fetch-public` to retrieve and verify the anonymous public products at their canonical paths; this includes the 15.3 GB compressed ED input bundle and roughly 24.5 GB of LUH2-GCB2026 files. Missing required items fail validation. Optional absences are reported as warnings.

The public retrieval scripts cover the complete official ED v3.0 release, GFED4.1s source files, GFED5 burned area, GFED5.1 monthly emissions, the ILAMB GFED4.1s reference, LUH2-GCB2026, and the pinned ILAMB-Data repository. The GFED5 burned-area and `fFire` references are generated locally from official source products. Their conversions aggregate extensive quantities by sum before division by area or time and run conservation checks.

TRENDY member outputs, licensed observations, coupled ED dumps, and lab-derived arrays are not anonymous downloads. Their retained copies already live at the declared paths; replacing or redistributing them still requires the relevant authorization. `sources.toml` labels these dependencies directly so procurement never substitutes another dataset.

The catalog contains 42 entries, including the official ED source, input bundle, release evidence, and the exact historical 1-degree GDP-per-capita grid needed to replay Models F and H. That GDP grid is a quarantined replay input, not an approved input for the clean research line. An experiment still consumes only the IDs declared in its own record, so an installed or globally required asset does not silently enter every run.

There is no `data/cache/`. A publisher archive is retained under `reference/` when it is provenance evidence; otherwise a partial or temporary download is removed after validated extraction. Reusable scientific transformations belong in `derived/`; transient experiment files belong in that run’s `work/` directory.
