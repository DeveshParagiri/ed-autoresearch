# Data layer

The data layer gives every scientific input a stable project path while storing large files in one canonical root outside Git. `catalog.toml` states each item’s role, the profile or experiment family that requires it, its project path, and its integrity checks. `sources.toml` records source identity, acquisition, release, coverage, units, preprocessing, limitations, access terms, integrity, experiment use, and recovery instructions.

`inputs/` contains climate drivers, ecosystem state, coupled state, human drivers, and candidate mechanism inputs. `benchmarks/` contains GFED observations, original GFED products, tracked ILAMB configurations, the native ED baseline, TRENDY outputs, and selected ILAMB-ready comparison models. `reference/` contains pinned conversion code and source notes. `derived/` is reserved for reusable products generated by recorded runs.

Run `python scripts/install_data.py plan` for a read-only report. Run `bash scripts/install_all_data.sh` to create links from a prepared ED-Fire data root and validate the result. Pass `--fetch-public` only when the official public products should be downloaded; LUH2-GCB2026 alone is about 24.5 GB. The installer refuses to replace regular files or links that point elsewhere. Missing required items fail installation. Missing optional items are reported with recovery instructions.

The public retrieval scripts cover GFED4.1s source files, GFED5 burned area, GFED5.1 monthly emissions, the ILAMB GFED4.1s reference, LUH2-GCB2026, and the pinned ILAMB-Data repository. The GFED5 burned-area and `fFire` references are generated locally from the official source products. Their conversions aggregate extensive quantities by sum before division by area or time and run conservation checks.

TRENDY member outputs, licensed observations, coupled ED dumps, and lab-derived arrays are not anonymous downloads. They must come from an authorized seed root. `sources.toml` labels these dependencies directly so a public-only setup stops with an accurate instruction instead of substituting another dataset.

The current catalog contains 38 entries. Ten are marked required across the offline, stock-baseline, benchmark-sensitivity, and emissions profiles; 28 support source reconstruction, coupled checks, candidate mechanisms, external comparison, and conversion tooling. All 38 are present in the current workspace. An experiment still consumes only the IDs declared in its own record, so an installed or globally required asset does not silently enter every run.

There is no project `data/cache/`. Public archives are either retained as declared source products or downloaded into a temporary directory and removed after validated extraction. Reusable scientific transformations belong in `derived/`; transient experiment files belong in that run’s `work/` directory.
